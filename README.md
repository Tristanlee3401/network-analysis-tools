## Installation
<pre>
git clone https://github.com/Tristanlee3401/network-analysis-tools
cd network-analysis-tools
</pre>

To compile C, run:
<pre>
gcc ip-to-bin.c -o ip-to-bin
</pre>

To execute Python, run:
<pre>
python3 subnet-calculator.py
</pre>
